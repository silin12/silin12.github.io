安装与升级

一键安装（按版本固定）

# 装 v1.0.1（当前版本，推荐）
TP_IMAGE_REPO=ghcr.io/silin12 TP_IMAGE_TAG=v1.0.1 bash <(curl -fsSL https://raw.githubusercontent.com/silin12/install-script/main/install_script.sh)

# 回退到 v1.0.0
TP_IMAGE_REPO=ghcr.io/silin12 TP_IMAGE_TAG=v1.0.0 bash <(curl -fsSL https://raw.githubusercontent.com/silin12/install-script/main/install_script.sh)

TP_IMAGE_TAG 默认 latest；不传就是拉 latest。卸载或换版本时请带上与安装时相同的 tag，否则单镜像清理会提示找不到镜像。

只换某个容器（不重装）

docker pull ghcr.io/silin12/trojan-panel-ui:v1.0.1
docker rename trojan-panel-ui trojan-panel-ui-old
docker run -d --name trojan-panel-ui --restart always --network=host \
  $(docker inspect -f '{{range .Config.Env}}-e {{.}} {{end}}' trojan-panel-ui-old) \
  $(docker inspect -f '{{range .Mounts}}-v {{.Source}}:{{.Destination}} {{end}}' trojan-panel-ui-old) \
  ghcr.io/silin12/trojan-panel-ui:v1.0.1
docker rm -f trojan-panel-ui-old
